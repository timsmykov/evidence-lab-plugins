# Russian Termbank for English-Source Texts

Use this reference for Russian academic and professional prose based on English-language sources, bilingual notes, source matrices, machine translation, or mixed English/Russian drafts.

This file is a default termbank. A user-provided or project-specific glossary overrides it.

## Operating Rule

Do not carry English source labels into final Russian prose just because they look precise. Preserve the concept, citation, and caveat; normalize the wording for Russian.

For each term, choose one of four actions:

- **Keep** — preserve as written.
- **Translate** — use a stable Russian equivalent.
- **Explain** — use an explanatory phrase instead of a fake compact term.
- **Internal only** — keep in notes, source plans, tables, or search logs, but not in final prose.

## Keep

Keep these when they are used as names, models, protocols, standards, source labels in internal work, or exact bibliographic data:

| Item | Rule |
|---|---|
| Author names in author-year citations | Keep original spelling: `du Plessis`, `Babić Rosario`, `Holliman & Rowley`. |
| Article/book/report titles | Keep exact source title when discussing or listing the source. |
| `PRISMA` | Keep as protocol abbreviation; explain once if needed. |
| `TAM`, `TPB`, `S-O-R` | Keep as model abbreviations after first expansion if the text discusses the models. |
| `B2B`, `B2C` | Keep if used as established business abbreviations. |
| `API`, `LLM`, `RAG`, `MVP`, `p-value` | Keep in technical contexts where Russian replacement would be less precise. |
| File names, dataset names, code, URLs, formulas | Preserve exactly. |

## Explain Rather Than Fake-Russify

Use an explanatory phrase when a compact literal translation sounds artificial.

| English source term | Avoid | Prefer |
|---|---|---|
| `product diagnosticity` | `диагностичность товара` as a standalone unexplained term | `достаточность информации о товаре для его оценки`; `способность информации помочь покупателю оценить товар` |
| `product fit diagnosticity` | `диагностичность посадки` | `насколько информация помогает оценить посадку товара` |
| `fit uncertainty` | `неопределенность посадки` | `трудности с оценкой посадки` |
| `fit risk` | `риск посадки` | `риск ошибки в посадке` |
| `return behavior` | `возвратное поведение` | `решения о возврате товара`; `частота возвратов` |

## Source-Base Wording

Use `корпус` only when the work actually uses a corpus in the strict sense: a compiled text collection for linguistic, corpus, textological, or quantitative textual analysis.

Avoid default AI-like phrases in Russian academic prose:

- `корпус источников`
- `корпус научных работ`
- `корпус публикаций`
- `корпус литературы`
- `исследовательский корпус`

Prefer:

- `источниковая база исследования`
- `база источников`
- `набор источников`
- `перечень источников`
- `массив научных работ`
- `массив публикаций`
- `выборка публикаций`
- `рассмотренные источники`
- `рассмотренные исследования`

Examples:

- `В корпус источников вошли 50 работ.` -> `Источниковая база исследования включает 50 работ.`
- `Корпус публикаций был отобран по критериям...` -> `Выборка публикаций была сформирована по критериям...`
- `Корпус научных работ показывает...` -> `Рассмотренные научные работы показывают...`

Allowed exceptions:

- `корпус текстов`
- `Национальный корпус русского языка`
- `параллельный корпус`
- `размеченный корпус`
- `подкорпус`
- any intentionally compiled and annotated text corpus used as research material.

## Internal-Only Labels

Keep these in notes, search strategies, source matrices, diagrams, or appendices only when they help organization. Do not use them as final Russian prose unless the user explicitly asks for bilingual terminology.

| Internal label | Main-text handling |
|---|---|
| `content marketing / digital content / branded content` | Convert to Russian prose by context. |
| `trust/risk` | Write `доверие и воспринимаемый риск`. |
| `fit/size/material/comfort uncertainty` | Write a Russian list: `трудности с оценкой размера, посадки, материала и комфорта`. |
| `UGC/eWOM` | Write `пользовательский контент, отзывы и онлайн-рекомендации` or project glossary form. |
| `AR/VTO` | Write `дополненная реальность и виртуальная примерка` or `виртуальная примерка`, by context. |
| `apparel/fashion/e-commerce literature` | Write `литература по электронной торговле, одежде и модной рознице`. |
| `return-related outcomes` | Write `результаты, связанные с возвратами`. |

## First-Mention Pattern

Use the English original at first mention only when it prevents ambiguity or connects directly to a named literature stream.

Preferred:

> В литературе этот механизм часто описывается через намерение покупки (purchase intention). Далее в тексте используется русский термин `намерение покупки`.

Avoid:

> Purchase intention является ключевым outcome в e-commerce.

If the Russian term is not stable, use an explanatory phrase instead of inventing a compact pseudo-term.
