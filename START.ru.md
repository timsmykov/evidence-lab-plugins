# Начало работы с Evidence Lab

Это точка входа для исследователя, который ещё не устанавливал Evidence Lab.
Пользователю не нужно запускать команды, разбираться в плагинах, Git или
технических настройках.

## Что делает пользователь

1. Открывает новую локальную задачу в Codex или Claude Code из папки, где будет
   находиться исследование.
2. Отправляет одно сообщение:

   > Настрой Evidence Lab для моей исследовательской работы из
   > `https://github.com/timsmykov/evidence-lab-plugins`. Используй только
   > последний опубликованный GitHub Release `release-*` и его
   > `release-lock.json`. Следуй `START.ru.md` и `BOOTSTRAP.md` из того же
   > релиза. Говори простым языком, задавай четыре вопроса по одному, покажи
   > полный рекомендуемый набор и ничего не устанавливай, пока я его не
   > подтвержу.

3. Отвечает на четыре коротких вопроса. Можно выбрать один или несколько
   номеров либо написать свой вариант.
4. Проверяет базовый исследовательский набор и персональные дополнения, затем
   отвечает «да», если полный набор подходит.
5. После завершения открывает новую задачу и сразу пишет настоящую цель
   исследования.

## Что происходит автоматически

Агент сам определяет приложение, проверяет последний стабильный релиз, проводит
короткий опрос и собирает набор возможностей по утверждённым правилам. До
подтверждения ничего не устанавливается. Команды и внутренние названия паков не
показываются, если пользователь сам не попросит технические детали.

База одинакова для всех исследователей: 20 фундаментальных скиллов. Ответы на
опрос помогают объяснить, что особенно полезно сейчас, и добавить профильные
возможности. Скиллы, которые ещё находятся в разработке, не выдаются за готовые.

Если стабильный релиз не удаётся безопасно проверить, настройка останавливается
до опроса. Агент не подменяет релиз веткой `main` или другим архивом.

## Как выглядит диалог

Первое сообщение агента:

> Я задам четыре коротких вопроса, затем покажу полный рекомендуемый набор и
> дождусь вашего подтверждения. Можно выбирать один или несколько номеров либо
> писать свой ответ.

Каждый вопрос показывает прогресс, все варианты ответа и фразу:

> Выберите один или несколько номеров либо напишите свой вариант.

После четвёртого ответа агент показывает понятный список возможностей: что
будет добавлено, зачем это подходит конкретному исследованию и какая версия
Evidence Lab используется. Установка начинается только после явного
подтверждения.

## Завершение

После проверки установки агент сообщает:

> Evidence Lab готова. Откройте новую задачу, чтобы приложение загрузило новые
> исследовательские возможности. Начните с того, над чем хотите работать;
> повторять настройку не нужно.

Если установка завершилась частично или с ошибкой, агент честно перечисляет,
что подтвердилось, и предлагает безопасное восстановление.
