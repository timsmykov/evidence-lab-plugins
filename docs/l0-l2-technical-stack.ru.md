# Технический стек L0–L2

Это минимальный стек Evidence Lab для первой консультации. Машиночитаемый источник истины — [`catalog/l0-l2-stack.json`](../catalog/l0-l2-stack.json). Эта страница нужна для быстрой проверки человеком.

## Граница бесплатного слоя

«Бесплатный L0–L2» означает, что Evidence Lab не требует платного расширения, MCP-сервиса или внешней системы памяти. Но исследователю всё равно нужен доступ к одному основному агенту. Для Codex или Claude Code может понадобиться подходящая подписка, организационный доступ, оплата API или одобренный облачный провайдер.

Второй агент подключается по желанию. Ни один компонент L0–L2 не должен требовать одновременного использования двух платформ.

## Профили

**Base** — единственный универсальный профиль. В него входят 13 компонентов: один маршрут доступа к провайдеру, один клиент, границы проекта, локальные средства контроля и жизненный цикл Evidence Lab.

**Documents** добавляет Poppler, OCRmyPDF, Pandoc, Quarto и Zotero, только если этого требуют материалы или формат результата.

**Data** добавляет локальное окружение Python через uv и, при необходимости, Jupyter. R остаётся отдельной дисциплинарной или лабораторной веткой.

## Что означают статусы проверки

- `docs-verified` — жизненный цикл или граница подтверждены актуальной документацией, но полного локального прогона нет.
- `locally-observed` — компонент или команда проверены на одном Linux-хосте. Это не доказывает чистую установку и полное удаление.
- `simulated-cross-host` — детерминированные тесты покрывают адаптеры двух платформ и ветки жизненного цикла с контролируемым readback.
- `live-cross-host` — чистая установка, рабочий сценарий, обновление, удаление и readback успешно пройдены на двух платформах. Сейчас такого статуса нет ни у одного компонента.
